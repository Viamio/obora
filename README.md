# Obora

Aplikacja do ewidencji krów: kolczyk, wycielenie, ruja, zacielenie, termin porodu (+280 dni),
przypomnienia o badaniu cielności, zasuszeniu i porodówce. Działa na Androidzie i iPhonie
(dodaj do ekranu głównego), z codziennymi powiadomieniami.

- `web/` – aplikacja (publikowana na GitHub Pages)
- `automat/` – codzienne powiadomienia (GitHub Actions, sekret `FIREBASE_SA`)
- `firestore.rules` – reguły bazy Firebase
